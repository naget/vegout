# AI造物·第2弹：自己做一个小程序

作为一个家电选购小白，面对现在琳琅满目的商品，不知所云的参数，真是不知如何下手。前段时间家里大采购，各种家电轮番轰炸，让我开启了「临时抱佛脚」式学习模式——买冰箱研究冰箱，买微波炉钻研微波炉，买扫地机器人就成为扫地机器人专家。

说实话，这个过程比我想象的要痛苦得多。每个品类都有无数参数、规格、技术名词，什么能效等级、制冷方式、变频定频……简直让人头大。

渐渐地，我发现了一个问题：每次都要重复学习这些知识，效率实在太低。而且大多数人其实没时间也没精力去深入了解每一个家电的门道，但又不想被商家忽悠或买错产品。

于是，一个想法在我脑中闪现：既然AI这么厉害，为什么不让它来帮我们完成这繁琐的学习和对比工作呢？

说干就干，我采用了「vibe coding」的方式（也就是对应第4级），开发了一个小程序——「帮你好好挑」。

这个名字听起来有点土，但很实在。它的功能也很简单粗暴：

功能一：告诉你该关注什么

买了新家电不知道看什么参数？别慌，输入品类，AI马上告诉你核心指标有哪些，哪些值得重点关注，哪些可以忽略。
功能二：帮你分析选得怎么样

看中了一款产品但不确定好不好？把型号/参数丢给AI，它会帮你分析优缺点，告诉你值不值得入手。
说白了，这就是一个家电选购的私人顾问，把我之前学到的那些知识都装进了程序里。从此以后，再也不用为了买个家电而临时变成半个专家了！

毕竟，人生苦短，何必为难自己？让AI帮你挑，你只管享受购物的乐趣就好。
